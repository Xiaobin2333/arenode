# CDNFly v6 功能能力矩阵

本文依据 CDNFly v6 普通用户 API 契约与 Arenode 兼容性测试整理。平台可持有多个上游普通用户 API 账号；客户账号由 Arenode 独立管理，不是 CDNFly 上游用户。

判定原则：一个功能只有在读取、写入、权限隔离、错误处理和状态回读都能闭环时才进入界面。仅能展示静态外观或无法验证结果的操作不实现。

## 可完整实现：调用 CDNFly，并由本地映射隔离

| 页面 / 功能 | CDNFly v6 接口 | 本地职责 | 结论 |
| --- | --- | --- | --- |
| 网站列表、创建、详情、修改、启停、删除 | `/v1/sites`、`/v1/sites/{id}` | 网站和套餐实例归属、本地 ID、额度检查 | 实现 |
| 网站分组 | PostgreSQL（站内） | 客户自定义分组不写入上游；网站仍归入该客户的隐藏上游组 | 实现 |
| 域名与 CNAME 检查、DNS 同步 | `/v1/domains`、`/v1/cname-check` | 先按租户网站过滤；使用上游返回的完整目标，或用账户配置的 CNAME 后缀组合主机名前缀 | 实现 |
| 证书管理与下载 | `/v1/certs` | 证书归属、DNS API 关联翻译、私钥脱敏 | 实现 |
| DNS API | `/v1/dnsapis` | 凭据不写审计正文、不跨租户返回 | 实现 |
| ACL 访问控制 | 当前上游 UI 实测 `/v1/acls` | 本地 ID、套餐实例归属、字段白名单和规则校验 | 实现（上游 UI 扩展） |
| CC 过滤器、匹配器、规则 | `/v1/cc-filters`、`/v1/cc-matchs`、`/v1/cc-rules` | 规则关联资源必须同租户 | 实现 |
| WAF 规则与网站编排 | `/v1/waf-rules`、`/v1/sites/{id}/waf-rules` | 自定义规则按客户隔离；系统规则只读 | 实现 |
| 四层转发与分组 | `/v1/streams` + PostgreSQL（站内分组） | 转发、端口、套餐实例归属；客户自定义分组不写入上游 | 实现 |
| 网站实时、排行、访问/攻击日志、黑名单 | `/v1/monitor/site/*` | 每次查询必须限定当前租户网站/域名；日志文档先列表后详情 | 实现 |
| 四层实时与排行 | `/v1/monitor/stream/*` | 只提交当前租户登记端口，并再次过滤结果 | 实现 |
| 分资源用量 | `/v1/monitor/usage` | 只查询当前套餐绑定资源，短 TTL 缓存 | 实现 |
| 刷新、预热、解封、日志下载任务 | `/v1/jobs` | URL、域名、网站及任务 ID 所有权校验 | 实现 |

## 不实现：上游账号范围内无法安全闭环

| 截图或 API 能力 | 原因 |
| --- | --- |
| 上游账号资料修改、实名认证 | 修改的是共享上游主账号，不属于下游租户 |
| 上游登录、注册、找回密码、验证码 | 下游身份由本平台管理，不能创建或修改共享上游账号 |
| 支付宝/微信预下单 | 收款主体和回调属于共享上游账号；平台本地订单没有可验证的上游支付闭环 |
| 上游套餐购买、增值和流量包订单 | 会直接修改共享套餐，无法归属到单个客户账号 |
| `/v1/user/overview`、`/v1/monitor/usage-count` 的原始结果 | 聚合整个共享上游用户；改为按租户资源重新计算 |
| 节点总流量 `/v1/node-traffic` | 包含共享节点上其他资源，无法证明租户归属 |
| 上游登录/操作日志 | 只记录共享 API 用户，无法识别本地客户账号；改用本地审计 |
| 上游账号策略、优惠券、共享套餐监控与共享任务/消息日志 | 数据属于共享上游账号，无法稳定映射到单个本地客户或本地账务 |
| 备份类任务 | 会放宽到上游用户范围，无法限定客户资源 |
| 仅有占位按钮、无对应读写接口的截图操作 | 无法完成状态回读和失败恢复，不进入成品界面 |

## 缓存与一致性

- PostgreSQL 是用户、租户归属、套餐、订单、审计和资源映射的唯一权威数据源。
- Redis 只保存可重建数据：GET 响应缓存、短期监控结果、请求合并锁和限流计数。
- CDNFly GET 请求按上游账号、路径、查询参数和客户范围生成缓存键；请求预算也按上游账号分别执行。写成功后失效缓存，不缓存业务错误。
- 站点/安全/转发列表默认 TTL 30 秒，监控默认 TTL 8 秒；详情写后立即失效。
- Redis 不可用时读请求直接访问 CDNFly，写请求照常执行；限流降级为进程内限制并在健康页告警。
