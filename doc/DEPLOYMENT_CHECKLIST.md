# 生产部署验收清单

## 1. 配置与密钥

- [ ] `APP_ORIGIN` 是外部 HTTPS 地址，反向代理传递正确的 Host 与协议。
- [ ] `DATABASE_URL`、`REDIS_URL` 使用生产专用账号和强密码。
- [ ] `SETTINGS_ENCRYPTION_KEY` 使用至少 32 字节随机值，已离线备份且未写入镜像。
- [ ] 每个 CDNFly 上游的 Base URL、API Key、Secret 已通过后台连接检测，凭据未出现在 API 响应或日志中。
- [ ] 每个在售平台套餐都映射到启用的上游套餐；已确认修改映射不会迁移既有客户资源。
- [ ] 初始超级管理员可登录；首次启动后已从环境移除 `ADMIN_PASSWORD`。
- [ ] `.env` 仅运行账号可读，容器日志和监控不会输出密钥、验证码或恢复码。
- [ ] 已演练存在生效客户套餐时禁止停用上游，跨上游迁移采用重新创建资源流程。

## 2. 注册与安全

- [ ] 新用户注册开关符合运营策略，注册和管理员创建客户均不会自动分配套餐。
- [ ] 开启邮箱验证前已发送 SMTP 测试邮件，发件域名的 SPF、DKIM、DMARC 正常。
- [ ] 开启 Turnstile 前已在后台完成配置测试；挑战通过前不能发送注册或找回密码验证码。
- [ ] 验证码邮箱/IP 冷却和小时上限已按实际流量设置。
- [ ] 服务条款、隐私政策、联系邮箱和公告内容已由负责人确认。
- [ ] 超级管理员已启用 MFA 并离线保存恢复码；至少保留两个可登录超级管理员。
- [ ] 普通管理员无法管理管理员账号或修改高风险运行参数。

## 3. 资金与订单

- [ ] 使用测试充值码完成充值，余额和不可变流水金额一致。
- [ ] 余额购买套餐立即生成已支付订单和套餐权益，不出现待管理员确认状态。
- [ ] 手动续费、自动续费、余额不足宽限期、宽限期恢复和最终到期均已演练。
- [ ] 同一自动续费任务重复执行不会重复扣款或重复延长套餐。
- [ ] 测试订单全额退款只成功一次，余额、订单状态和对应权益同时回滚。
- [ ] 余额调整必须填写原因并二次确认，任何操作都不能产生负余额。
- [ ] 财务日期筛选与数据库抽样流水一致；确认平台没有 CSV 导出入口。

## 4. 资源与上游

- [ ] 创建、更新、启停和删除网站均使用 CDNFly v6 普通用户 API 成功完成。
- [ ] 不同客户无法读取或修改彼此的网站、转发、安全资源、日志和订单。
- [ ] 用量同步时间正常；域名、流量和端口超限会暂停对应套餐资源，扩容后自动恢复。
- [ ] Redis 缓存命中、写后失效和上游请求预算符合预期。
- [ ] CDNFly 故障时本地资金事务不会留下半完成订单或半生效权益。

## 5. 数据库与恢复

- [ ] 执行 `docker compose exec -T postgres pg_dump -U cdnfly -d cdnfly_reseller -Fc > arenode.dump`。
- [ ] 在隔离数据库执行 `createdb` 后使用 `pg_restore --exit-on-error --no-owner --dbname=<restore_db> arenode.dump`。
- [ ] 核对 `users`、`orders`、`wallet_transactions`、`subscriptions`、`sites` 和 `audit_logs` 数量。
- [ ] 抽样核对每个钱包最新流水的 `balance_after_cents` 与 `wallets.balance_cents`。
- [ ] 使用恢复库启动单实例，验证登录、客户详情、订单详情和只读列表后再结束演练。
- [ ] 备份已加密并异地保存，恢复步骤和责任人已记录；Redis 不作为业务恢复来源。

## 6. 指定测试资源回归

- [ ] 使用专用客户账号和专用资源，不与生产客户共享域名、证书或监听端口。
- [ ] 设置 `REAL_TEST_DOMAIN`、`REAL_TEST_EXPECTED_CNAME` 和 `REAL_TEST_UPSTREAM_PACKAGE_ID`，并确认网站写测会保留回读到的源站、协议与启用状态。
- [ ] 需要测试四层转发时，完整设置 `REAL_TEST_STREAM_ID`、`REAL_TEST_STREAM_PORT`、`REAL_TEST_STREAM_ORIGIN` 和 `REAL_TEST_STREAM_BACKEND_PORT`；脚本不得发现白名单外资源。
- [ ] 真实烟测仅通过 `RUN_REAL_CDNFLY_TESTS=1`、`REAL_TEST_BASE_URL` 和专用登录凭据显式启用；默认只读，不执行删除或更新。
- [ ] 只有人工复核所有白名单变量后才设置 `RUN_REAL_CDNFLY_WRITE_TESTS=1`；写测只做指定资源的幂等更新和 CNAME 检查，不创建或删除资源。
- [ ] 上游只返回 CNAME 主机名前缀时，后台上游账户已配置正确的 CNAME 后缀。

## 7. 监控与发布

- [ ] 后台系统状态的 PostgreSQL、Redis、CDNFly、计费任务和邮件服务符合预期。
- [ ] 计费任务最近运行成功，单实例和多实例 advisory lock 行为均已确认。
- [ ] 已配置邮件发送测试通过；确认不存在站内通知和工单入口。
- [ ] 桌面和 390px 移动端完成登录、注册、找回密码、购买、充值、MFA 和后台关键页验收。
- [ ] `npm test` 全量通过，容器使用当前源码重新构建且启动日志无迁移错误。
- [ ] 已定义回滚镜像与数据库切换方案；涉及不可逆数据迁移时先停止发布并恢复演练。
